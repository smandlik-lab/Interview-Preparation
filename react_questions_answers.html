React.js Interview Questions

30 Core Questions & Concise Answers Categorized by Experience Level

Beginner Level

Foundational
1.

What is React.js?

A JavaScript library for building user interfaces, developed by Facebook, using reusable components and a Virtual DOM.
2.

What are the main features of React?

Includes Virtual DOM, component-based architecture, one-way data binding, JSX, and React Hooks.
3.

What is JSX?

JavaScript XML; a syntax extension that allows writing HTML-like code inside JavaScript to describe UI.
4.

Difference between functional and class components?

Functional components are simple functions taking props and returning JSX; class components use the render method and can hold state.
5.

What are props?

Read-only properties passed to components to make them dynamic.
6.

Create a button that changes color on click?

Use the useState hook to manage color state and update it via an onClick event.
7.

Display a username greeting?

Pass a username prop to a functional component and render it dynamically.
8.

Output of provided code?

Explains how useState and setCount update the component state, triggering a re-render.
9.

Create a list using map()?

Use the .map() method to iterate over an array and generate elements, each with a unique key prop.
10.

Conditionally render a component?

Use ternary operators or logical AND (&&) operators.

Intermediate Level

1–2 Years Exp
11.

State vs. Props?

State is mutable and managed internally; props are immutable and passed from parents.
12.

How does Virtual DOM work?

It creates a lightweight copy of the real DOM, calculates differences (diffing), and updates only the necessary parts.
13.

React Hooks?

Functions like useState (state management), useEffect (side effects), useContext (global state), and useRef (DOM access).
14.

Context API?

Shares state across components without manual prop drilling.
15.

React Router?

A library for handling navigation in React applications.
16.

Pass data child to parent?

Pass a callback function from the parent as a prop to the child.
17.

Fetch API data?

Use useEffect to trigger an API call upon component mounting.
18.

Prevent unnecessary re-renders?

Use React.memo (functional) or shouldComponentUpdate (class components).
19.

Handle form submission?

Use controlled input fields with useState and an onSubmit handler to prevent page refresh.
20.

Lazy loading?

Loads components only when needed using React.lazy and Suspense.

Advanced / Experienced Level

Architecture & Performance
21.

What is reconciliation?

The process of updating the DOM by comparing the Virtual DOM with the real DOM.
22.

Higher-Order Components (HOCs)?

A pattern where a function takes a component and returns an enhanced component.
23.

useCallback vs. useMemo?

useCallback memoizes functions; useMemo memoizes computed values.
24.

Server-Side Rendering (SSR)?

Renders components on the server and sends the final HTML to the client.
25.

What is React Fiber?

The new reconciliation algorithm designed to improve performance.
26.

Optimize slow components?

Use memo, useMemo, and minimize unnecessary state updates.
27.

Authentication?

Use JWT tokens stored in local storage managed via Context Providers.
28.

Handle memory leaks?

Use useEffect cleanup functions to remove event listeners or clear intervals.
29.

Infinite scrolling?

Implement via IntersectionObserver or scroll event listeners.
30.

Debug performance issues?

Use React Developer Tools, the Profiler API, and identify unnecessary renders.
